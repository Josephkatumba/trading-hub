# Product Plan

## Product thesis

Trading data is fragmented across brokers, prop firms, platforms, spreadsheets, screenshots, and journals. The platform brings that activity into one trader-owned workspace.

## Core user journey

1. Create an account.
2. Add one or more trading accounts.
3. Import or connect trading data.
4. See a unified portfolio dashboard.
5. Explore individual trades and performance.
6. Receive automated insights.
7. Compare performance over time.
8. Later, participate in the community and marketplace.

## V0.1 scope

### Dashboard
- Total equity
- Total P&L
- Return
- Drawdown
- Win rate
- Profit factor
- Average trade
- Equity curve
- Recent trades
- Account breakdown

### Accounts
Every user can have multiple trading accounts.

Each account stores:
- Name
- Broker/platform
- Account type
- Starting balance
- Current balance
- Currency
- Status
- Trade history

### Trades
Each trade should support:
- Symbol
- Direction
- Entry
- Exit
- Volume
- Stop loss
- Take profit
- P&L
- Open time
- Close time
- Strategy/tag

## Demo-first development

V0.1 will use realistic seeded trading data. Real broker integrations come later.

This lets us validate:
- UX
- information architecture
- analytics
- data model
- AI reporting concepts

without waiting for external APIs.
