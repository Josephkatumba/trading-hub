# V0.1 UI

## Navigation

- Overview
- Accounts
- Trades
- Analytics
- AI Insights
- Settings

## Overview

The first screen should answer:

**How am I doing?**

Top cards:
- Equity
- P&L
- Return
- Drawdown
- Win Rate
- Profit Factor

Main visual:
- Equity curve

Secondary sections:
- Account performance
- Recent trades
- Best instruments
- Trading sessions
- Recent insights

## Design direction

Dark, premium, data-rich, but uncluttered.

The interface should feel like a modern professional trading terminal rather than a spreadsheet.
